title: Dokumentation
subtitle: OpenProject-Plugin Dokumentation
---
Diese Dokumentation beschreibt die Verwendung vom scm-openproject-plugin. Sie steht in verschiedenen Sprachen und Versionen zur Verfügung, die im Menü rechts ausgewählt werden können.
Dieses Plugin ist kompatibel mit OpenProject. Es ermöglicht die automatische Erstellung von OpenProject Ticket Kommentaren auf Grundlage der Commit Nachricht. Zusätzlich lässt sich über definierte Stichwörter innerhalb der Commit Nachricht der OpenProject Ticket Status aktualisieren.
